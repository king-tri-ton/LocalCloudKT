# LocalCloudKT

**LocalCloudKT** — это локальное файловое хранилище для домашней сети, созданное на Python с использованием Flask. Проект позволяет загружать, скачивать и удалять файлы через веб-интерфейс с авторизацией.  

---

## Возможности

- Вход по паролю с ограничением количества попыток
- Просмотр файлов и папок с сортировкой по дате
- Загрузка нескольких файлов одновременно
- Скачивание и удаление файлов
- Автоматическое создание подпапок по дате (`Год/Месяц/День`)
- Легкая установка и настройка через `install.py`
- Управление сервером через BAT-скрипты: запуск, остановка, перезапуск
- Поддержка работы в локальной сети с использованием статичного IP
- Сервер запускается на **порту 80**. Если порт занят другим приложением, сервер не запустится  

---

## Требования

- Python 3.13
- Windows (для использования BAT-скриптов)
- Статический IPv4 на ПК, где запускается сервер
- Установленные библиотеки:
  ```bash
  pip install -r requirements.txt
````

---

## Установка

1. Клонируйте репозиторий на ПК с Windows:

   ```bash
   git clone https://github.com/king-tri-ton/LocalCloudKT.git
   cd LocalCloudKT
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите установку:

   ```bash
   python install.py
   ```

   * Введите секретный ключ (или нажмите Enter для генерации)
   * Укажите путь к корневой папке хранения файлов (по умолчанию `C:\LocalCloudKT`)
   * Введите пароль для входа

4. После установки перезапустите терминал или ПК, чтобы новые переменные окружения стали доступны.

---

## Запуск сервера

* Запуск:

  ```cmd
  LCKT_start.bat
  ```
* Остановка:

  ```cmd
  LCKT_stop.bat
  ```
* Перезапуск:

  ```cmd
  LCKT_restart.bat
  ```

Логи работы сервера сохраняются в папке `logs\server.log`.

**Важно:** сервер запускается на порту **80**. Если порт занят другим приложением, запуск не состоится.

---

## Использование

1. Откройте браузер и перейдите по адресу: `http://<статический_IP_ПК>/`
2. Введите пароль для входа.
3. Загружайте, скачивайте или удаляйте файлы через веб-интерфейс.
4. Файлы будут храниться в подпапках по дате.

---

## Безопасность

* Пароль хранится в виде хэша (`werkzeug.security`)
* Ограничение количества попыток входа (3)
* Безопасная работа с файлами с помощью функции `safe_join`

---

## Замечания

* Сервер должен запускаться на ПК с **статическим IPv4**, чтобы другие устройства в сети могли стабильно подключаться.
* Работает только в локальной сети по IP указанного ПК.
